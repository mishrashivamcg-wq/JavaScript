Assignment: Introduction to JavaScript

Section A: Short Answer Questions

Q1. What does it mean when we say JavaScript is a high-level programming language?

JavaScript is a high-level programming language because it is easy for humans to read and write. It hides complex computer operations from the programmer.

Q2. Is JavaScript a compiled language or an interpreted language?

JavaScript is commonly called an interpreted language. Modern JavaScript engines also use Just-In-Time (JIT) compilation to make the code run faster.

Q3. Name the JavaScript engines used by the following browsers.

  • Google Chrome: V8
  • Mozilla Firefox: SpiderMonkey
  • Apple Safari: JavaScriptCore

Q4. What is Dynamic Typing in JavaScript?

Dynamic typing means that a variable can store different types of values during the program.

Example:

let x = 10;
x = "Hello";
x = true;

Q5. Explain ECMAScript. What is its relation with JavaScript?

ECMAScript is the standard or specification that defines how JavaScript should work. JavaScript is an implementation of the ECMAScript standard.

  1. Event Handling: JavaScript can respond to events such as clicks, typing and mouse movements.
  2. DOM Manipulation: JavaScript can change HTML content, elements and styles without reloading the page.

Q9. Difference between internal and external JavaScript.

JavaScript can be written directly inside an HTML file using the <script> tag. 

<script>
    alert("Hello");
</script>

In external JavaScript, the code is written in a separate .js file and connected to HTML. 

<script src="script.js"></script>

Advantages of external JavaScript:

  1. The same JavaScript file can be used on multiple pages.
  2. It keeps HTML code clean and easier to maintain.

Section E: Higher Order Thinking

Q14. Why did JavaScript become so popular and multipurpose?

JavaScript became popular because it is easy to learn and works directly with web browsers. It can create interactive websites and has a large community and many useful libraries and frameworks.

Node.js made it possible to run JavaScript outside the browser, which allowed developers to use it for backend development.

ECMAScript updates regularly added new features and improvements to JavaScript, making it more powerful and useful for different types of applications such as web, mobile, desktop and AI applications.
